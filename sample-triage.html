Use it honestly

A prioritization aid—not a safety answer.

The tool helps decide which water samples might move first through a limited particulate domoic-acid assay queue—a laboratory test for toxin attached to material in the water sample. It never says that a sample, beach, shellfish, or animal exposure is safe.

1

Enter what is back

Add both microscope groups when reported, SST, and chlorophyll only if available. A missing group remains missing.

2

Review one sample

Use the historical band to see whether the observed count is ordinary or unusually high for this seven-pier archive.

3

Rank the real batch

Enter every sample facing the same laboratory decision and set the actual number of expedited slots. The queue is the operational output.

What remains unproven

No prospective validation. The rule has only been replayed on historical California pier data.

No calibrated probability. The historical band rate describes old same-sample observations; it is not the chance that this new sample contains toxin.

No automatic transfer. Other locations can use the transparent batch ranking, but the historical reference bands represent seven California piers only.

Normal protocols still apply. A lower queue rank must never be read as “safe” or “do not assay.”
